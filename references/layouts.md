# 图像主导的科研汇报

参考朱河勤的 structRFM 学术报告所采用的组织方式：围绕一个研究问题，从背景转到模型与数据，再用基准、难例和局限完成论证。此技能用原创布局实现这种组织方式。

| 页面 | 用于 | 页面核心 |
| --- | --- | --- |
| `cover` | 开场 | 研究题目和汇报场景 |
| `flow` | 研究动机、数据或方法 | 两到五个可命名的环节，每个环节讲清它改变了什么 |
| `figure` | 方法全图、基准、难例 | 一张图拉满阅读区，或两张图并排回答同一个问题 |
| `points` | 对照设计、局限、讨论 | 两到四条有具体对象的陈述 |
| `closing` | 结束 | 结论或讨论问题 |

先让听众知道问题，再告诉他们看图里的哪里。对多分面图，可选关键分面或拆成连续页面。方法页优先解释输入、变化和输出。实验页把「比较谁、在哪个数据集、用哪个指标」写入正文、图注或备注。保留最强基线和不利结果，避免将单任务改善推广到所有任务。

`source` 写短出处，例如“论文 DOI · 图 3d，p. 5”或“实验 E07 · 评估表第 4 行”。`notes` 可以写开场过渡、读图路径、结论边界和本页时长。不要从低清图中推测精确数字。对作者原图的重绘要在来源行标明“重绘”。

默认使用浅色画布、左对齐题目、青色强调和底部来源。示例内容是为技能编写的演示素材。
