# 图像主导的科研汇报

参考朱河勤的 structRFM 学术报告的编排。从背景收束到明确问题，再用方法图、基准比较和难例逐步回答。作者报告的 PDF 第 7–8 页提出结构信息如何进入预训练，第 11 页单独展开遮盖机制，第 17–18 页依次看盲测结果和难例。正式结果、数值和数据集名称用发表版核对。原图与正文有差异时，把影响理解的差异放在图旁。

| 页面 | 用于 | 页面核心 |
| --- | --- | --- |
| `cover` | 开场 | 研究题目和汇报场景 |
| `flow` | 关系比原图更适合用简图解释的方法 | 两到五个短步骤，用位置和箭头表达先后 |
| `figure` | 方法、基准、难例 | 放大一个主图，或用两幅有关联的图回答同一个问题 |
| `table` | 模型概览、方法对照、定量汇总 | 可编辑表格，表头浅灰蓝，按同一口径逐行比较 |
| `points` | 讨论与无法用图表达的限制 | 两到四条具体陈述，必要时左列用短标签带读 |
| `closing` | 结束 | 结论或讨论问题 |

## 如何让重点先被看到

- **决定一页讲什么，再决定怎么放。** 动机、机制、对照和边界页适合用原图能回答的具体问题作标题。背景、模型概览和结论页可以用短标题。标题已给出答案时，图下文字用来说明实验条件、读法和例外。
- **跨材料用问题转场。** 保留一个统一封面和连贯页码，把重复背景讲一次。上一部分收束到听众理解的一个未决问题，下一部分接着回答。例如先提出泛化问题，再解释测试划分，最后用一篇论文展开方法与证据。具体章节和页数按实际材料决定。
- **把空间给证据。** 流程图讲一个变化，结果页讲一个比较。对多分面图按论证挑选或拆分。并排用于逐项对照，两张很宽的图可上下放。需要听众频繁在两张图之间来回找信息时，分两页。
- **用字号、对齐和留白形成层级。** 封面以居中深蓝主标题、短副标题和场合信息开场。正文标题顶端居中，通常约 30 pt，焦橙色（`#A94F13`）用于一个短关键词或一处图内强调。图居中放大，短图注靠近证据。原图用于区分模型、类别和变量的颜色完整保留。
- **统一对照的读法。** 同类小图并排或上下对齐，使用简短的可编辑中文标签标出各自的条件。模型清单、微调选项和评估口径可用原生表格，优先只保留现场需要比较的列。内容密集时，在相邻两页用同样的表头和列序继续，保留原来的字号。
- **把反例摆在观众面前。** 保留强基线和不利结果。若整体性能和局部例子各回答一个问题，让前后两页分别展示。实验页至少让听众知道比较对象、数据集与指标含义。会改变结论的条件就近写在图注或短句里，其余移入讲稿。

## 清单字段

- `source` 是页左下角的单行引用或数据来源，正文页码放右下角。`notes` 放先指哪里、再比较什么、怎么过渡，以及完整出处。已确定汇报时长时，可在每页备注开头写建议用时。
- `takeaway` 可选，用于图中难以直接读出的关键结论或适用条件。默认是普通文字。留空时图可使用更多空间。
- `emphasis` 可选，填标题中实际出现的一个短语。也可在单个图片对象中用 `"highlight": [x, y, width, height]` 标出要讲的区域。坐标为相对于裁后图片左上角的比例，使用前检查细线是否挡住坐标或数据。每页最多选一种强调方式。
- `figure` 支持一个或两个图。布局默认 `row`，两张宽图可用 `"layout": "stack"` 上下排列。图片对象的 `caption` 用单行短标签，紧跟各自的图。图内已有充分说明时可省略。
- `table` 用 `rows` 提供二维数组，首行为表头。可用 `column_widths` 设置各列相对宽度，用 `lead` 提供一行读表提示。列宽默认均分。可直接改动 PPTX 中的每个单元格。
- `points` 可用短字符串作为项目符号，或用一组 `{"label": "短标签", "body": "一句陈述"}` 生成两列对齐的版式。

## 页脚引用

引用论文观点、数值、图表或数据集时，在使用它的那一页左下角写一行小号灰字。采用“作者，年份 · 定位”，例如“作者等，2025 · 图 3d–e”或“Author et al., 2025 · Table 2”。同一篇论文的多个分面合写。也可用页码、章节名或数据版本定位。核对不到作者或年份时，用已核实的短标题或标识。自有实验可用“实验编号 · 结果表”说明来源。

一页有多篇文献时，用分号分开，必要时写明“左图 / 右图”。重绘或改编就在对应引文后标“重绘”或“改编”。作者全名、完整标题、期刊和 DOI 放进演讲者备注。需要正式文献表时，可另放在末尾，仍在相关页保留短引。

页脚沿用白底、小号灰字和左对齐，省去色带、卡片、边框和图标。空间有限时优先保留作者、年份与定位。若一页来源太多，可用短编号对应备注或文献表，并核对投影时能辨认。
